# DeepSeek Harness：分阶段完整输出（可选）

通用 write 方法不依赖某个应用。若在 DeepSeek Harness 中希望默认完整展示各阶段、自动继续并在完成后停止，可把下方规则追加到目标写作工作区的 `AGENTS.md`，保留该文件已有约定；不要用此示例覆盖整份文件。

前提是当前应用已经具备并启用了原生 Goal、续轮驱动器和支持 `blocked_by` 的原生团队任务。以下约定已在 DeepSeek Harness 0.2.1-rc.2 的同一测试对话中，用短任务验证过完整展示、自动续轮和完成停止。其他版本、配置及新对话仍须核实实际运行；文字约定与任务依赖不能保证模型始终遵守全部语义步骤，也不能证明独立审读的上下文隔离。此示例不要求安装插件。

## 默认分阶段执行（DeepSeek Harness）

- 本工作区的小说任务默认按 write 的适用阶段完整展示成果。跨阶段、需多轮推进时，由收到作者直接请求的主对话读取当前 goal；没有未结束目标时创建原生 Goal，已有目标先核对范围，不覆盖其他任务。单轮可完成的构思、大纲、审读或局部修改等单阶段任务直接交付，不扩成整套流程；原生工具不可用时如实说明，不模拟自动续轮或另装替代工具。
- 按本次实际所需阶段建立原生团队任务，以 `blocked_by` 连接先后依赖；已有材料直接接入，不固定每次六阶段、不另造状态库、不为每阶段新建成员，也不用一次 `workflow` 包住全部流程。
- 每轮推进一个阶段，或长正文的一个自然章节/片段：核对实际产物与当前版本后完成对应任务，在主对话完整展示该阶段成果，再结束本轮。初稿与修订要展示全文，不能用链接、摘要或“已完成”代替；规划、方案和审读说够即止，不为流程凑长表。
- 本轮授权范围尚未完成时，Goal 保持 active，由内置续轮驱动器继续，不要求作者反复说“继续”。自动推进不包含关键剧情代选权：相关关键方案尚未由作者选定、且未明确授权本轮代选时，先把本轮目标限定到关键方案的比较与交付，交付后停止，明确正文尚未写；作者选定或明确委托本轮代选后再推进后续范围。
- 本轮目标内所有适用阶段及必要复查完成后，先核实产物、完成任务，再读取最新 goal 并标记 complete，给出最终交付后停止；不自动开新审读、续写新章节、扩大范围或创建下一个目标。
- 创建目标时设置有限的 `max_goal_rounds`：短任务默认8轮，长任务按本次章节范围合理设置；不把整部长篇自动包成一个目标，不擅自增加上限。耗尽或失败如实报告，不冒称完成。会话恢复或 fork 后，不自行恢复自动工作；须作者直接授权继续。协作室或子代理消息不能替代原生 Goal 所需的直接人类授权。
