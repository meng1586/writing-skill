# 规则摘要格式演示

> 独立虚构的教学情境，仅演示格式，效果未经验证；它不是从现有项目改名而来的案例，不纳入随包经验的试用证据。

## R-开篇-DEMO-001 信息发生变化后，检查人物回应是否随之调整

- **适用题材**：悬疑 / 通用
- **适用条件**：人物刚获得与当前决定有关的新信息，需要判断这条信息是否会改变他的选择
- **可以尝试**：比较新信息前后的动作或回答，检查变化或维持原状是否有依据
- **为什么值得试（推测）**：回应的变化可能让人物取舍更容易被看见；保持原样也可能有合理动机
- **边界**：不能仅因人物没有立刻改变决定就判错，需考虑他是否相信信息、是否有其他约束
- **效果状态**：待试验

## 独立虚构情境

邮差准备把一封蓝色信交给修表匠，临到门前才发现收件人印章与信封不符。这里只提供一个新造的练习条件，用来演示“新信息是否改变当前动作”的提问方式，不声称某种改法更有效。
