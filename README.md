# 写作学习与候选卡片

把阅读中的观察整理成写作时可查询的判断，再用试写和反馈调整适用范围。

公开包提供方法、工具，以及 47 条规则摘要（8 个维度）、24 条决策摘要、12 张场景摘要；它们不是已经证明普遍有效的写作定律。你可以继续加入自己的材料，但脚本不会替你完成阅读理解或宣布写作效果。

## 包含什么

- **阅读方法**：选材、三层阅读、笔记、宏观结构与改稿检查。
- **规则摘要**：按维度保存的 Markdown 条目，保留原编号、条件、动作、解释、边界和试用状态。
- **决策摘要**：JSON 条目，按题材、场景和位置检索。
- **场景摘要**：Markdown 卡片，提供可选择的结构与容易出问题的情形。
- **反馈工具**：索引、文风统计、试写回填和使用问题记录。

原文摘引、具体来源定位、完整阅读记录与项目正文保存在本地完整版中，不随本包分发。公开摘要仍保留适用条件和效果状态；删去来源不等于证明了效果。

## 快速开始

在本包根目录执行，Python 脚本只依赖标准库：

```bash
# 看阅读计划；空书架是正常状态
python3 skills/novel-study/scripts/plan.py

# 查询随包候选，是否采用由当前作品目标决定
python3 skills/novel-study/scripts/apply.py --tags 悬疑 --no-write
python3 skills/writing-decision/scripts/decide.py --tags 玄幻 --scene 第一次杀人 --json
python3 skills/scene-modules/scripts/query.py --list

# 看回填记录；没有记录时不会假装已验证
python3 skills/writing-loop/scripts/writeback.py report
```

`apply.py` 去掉 `--no-write` 会把备忘写入本包根目录下的 `06-素材/写作/备忘/`。书架管理、采集和文风档案按需使用，各入口的 `--help` 给出实际参数；联网采集取决于所选来源当时是否可用，不是查询摘要的前置条件。

## 数据在哪里

```text
skills/
├── novel-study/
│   ├── config.json
│   ├── data/shelf.json       # 空书架，后续阅读记录留在使用者本地
│   ├── data/notes/           # 本地阅读笔记的位置
│   └── data/rules/           # 随包规则摘要
├── writing-decision/data/decisions.json
├── scene-modules/data/modules/
├── writing-loop/data/index.jsonl
└── skill-reflect/            # 使用问题记录与报告
examples/                    # 独立虚构的格式演示，效果未验证
```

`plan.py --sync` 按配置把笔记、规则同步到 `06-素材/读/笔记/` 和 `06-素材/读/规则/`。索引、文风档案、回填和复盘记录在使用者本地逐步生成，不预装原项目的阅读进度。

## 怎样继续积累

1. 为本次阅读或写作定一个具体问题。
2. 查候选摘要，核对人物状态、读者已知信息、叙述视角和本场目标；允许全部不用。
3. 用少量改动试写并回读。反馈写清条件、具体变化和证据范围。
4. 只有实际试用才能更新试用结论；文本中多次出现某种写法，不等于照用有效。

规则、决策和场景卡分别保留各自格式，见各模块的 `SKILL.md`。完整方法见 [写作方法论](写作方法论-v2.md)，文件及来源版本见 [清单](MANIFEST.md)。本地原有完整版继续用于创作，公开整理不要求重写旧笔记或迁移写作进度。
