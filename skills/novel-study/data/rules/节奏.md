# 节奏

> 维度：节奏 · 规则数：4 · 最后更新：2026-10-21

## R-节奏-001 规则要一次讲透，规则揭示本身就是爽点

- 为什么：读者要的是「解题条件」，不是「谜题」。规则讲清楚，读者才能和主角一起算；挤牙膏式放规则，读者只能干等。
- 出处：《十日终焉》第 2 章
- 正例：「若八个人全部都选中了「说谎者」，说谎者出局，其余人全部存活。若有其中一人选错，则说谎者存活，其余人全部出局。」
- 反例：规则分十章透露，每章只给一条——读者算不出胜负条件，追逐感变成困惑感，追读动机消失。
- 适用题材：游戏流 / 无限流 / 系统流 / 智斗
- 适用条件：规则本身有推理空间；纯升级流可简化
- 状态：可用

## R-节奏-002 让读者先于配角知道主角要赢

- 为什么：爽感来自「我知道他要赢，而场上的人还不知道」。主角在心里算完、读者跟着算完，揭晓时是验证，不是惊讶——验证比惊讶更爽。
- 出处：《十日终焉》第 3 章
- 正例：「所以他准备叫自己「李明」。」／「游戏已经要结束了。」
- 反例：主角最后突然说出答案，读者毫无参与——变成「作者安排的聪明」，不是「主角的聪明」。
- 适用题材：智斗 / 推理 / 无限流 / 权谋
- 适用条件：需要读者掌握同等信息；信息不对称设计的悬疑不适用
- 关联：R-章末钩子-001
- 状态：可用

## R-节奏-003 给每次取胜标价：消耗、时限、事后后悔

- 为什么：无代价的胜利是发糖，有代价的胜利才是赌局。读者看见主角赢了，同时看见他付了什么，下一次赢才有分量；只报喜的爽点，三章就腻。
- 出处：《异兽迷城》正文第 26—35 章
- 正例：每次赢完立刻写清消耗了什么、还剩多少时间、事后哪里后悔——系统给的资源要还，伤要养，人情要欠。（第 26—35 章）
- 反例：主角一路开挂，赢了只写「众人震惊，高阳微微一笑」——读者不知道他付出了什么，赢变得廉价。
- 适用题材：系统流 / 都市高武 / 热血升级
- 适用条件：需要长线升级；纯无脑爽文可少标价，但不能完全不标
- 关联：R-结构-002
- 状态：可用

## R-节奏-004 危险与危险之间插一顿夜宵、一通电话，让人喘口气

- 为什么：全程绷紧等于没绷紧。读者需要一段低强度的日常把人物拽回来，才知道上一次危险有多险；但喘气段不能解决问题，只能延迟问题，否则节奏塌掉。
- 出处：《异兽迷城》正文第 26—35 章
- 正例：刚出完人命，转头写一顿夜宵、一个电话、一句家常，人物刚坐下，下一件事就找上门。（第 26—35 章）
- 反例：打完一场立刻接下一场，中间只写「他们没有休息，继续赶路」——读者疲劳，打斗的强度互相抵消。
- 适用题材：悬疑 / 热血 / 无限流
- 适用条件：连续高强度单元之间；单章短篇不必硬插
- 关联：R-语言-001
- 状态：可用
