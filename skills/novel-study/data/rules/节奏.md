# 节奏

> 维度：节奏 · 规则数：2 · 最后更新：2026-10-20

## R-节奏-001 规则要一次讲透，规则揭示本身就是爽点

- 为什么：读者要的是「解题条件」，不是「谜题」。规则讲清楚，读者才能和主角一起算；挤牙膏式放规则，读者只能干等。
- 出处：《十日终焉》第 2 章
- 正例：「若八个人全部都选中了「说谎者」，说谎者出局，其余人全部存活。若有其中一人选错，则说谎者存活，其余人全部出局。」
- 反例：规则分十章透露，每章只给一条——读者算不出胜负条件，追逐感变成困惑感，追读动机消失。
- 适用题材：游戏流 / 无限流 / 系统流 / 智斗
- 适用条件：规则本身有推理空间；纯升级流可简化
- 状态：可用

## R-节奏-002 让读者先于配角知道主角要赢

- 为什么：爽感来自「我知道他要赢，而场上的人还不知道」。主角在心里算完、读者跟着算完，揭晓时是验证，不是惊讶——验证比惊讶更爽。
- 出处：《十日终焉》第 3 章
- 正例：「所以他准备叫自己「李明」。」／「游戏已经要结束了。」
- 反例：主角最后突然说出答案，读者毫无参与——变成「作者安排的聪明」，不是「主角的聪明」。
- 适用题材：智斗 / 推理 / 无限流 / 权谋
- 适用条件：需要读者掌握同等信息；信息不对称设计的悬疑不适用
- 关联：R-章末钩子-001
- 状态：可用
