# 章末钩子：公开摘要

> 保留提炼后的条件与候选办法；原文、来源定位和真实案例留在本地。
> 所有效果均待试验。按当前文本选择，允许不用；固定数量、句式或步骤不作为质量门槛。

## R-章末钩子-001 按本章后果选择不同的收束落点

- 适用题材：通用，除单章完结需另判断外
- 适用条件：连续章节的结尾反复提供同类等待，而当前事件有不同后果可落。
- 可以尝试：比较认知、关系、情绪、动作或日常落点，选最贴合本章变化的一种。
- 解释（推测）：落点变化可能使等待不只依赖同一种悬念形式。
- 边界与失败方式：不按次数强制轮换；同类收法可累积意义，完整收束也不需要制造未完问题。
- 效果状态：待试验

## R-章末钩子-003 尝试用物件、问题或可见变化承载收尾

- 适用题材：连载长篇 / 悬疑 / 系统流
- 适用条件：本章新出现或改变的具体事物值得被读者带到下一段。
- 可以尝试：在物件、短问与可见变化等落点中选择有情节依据的一项。
- 解释（推测）：具体落点可能使当前变化更容易被记住并继续关注。
- 边界与失败方式：这些只是备选，不要求三种轮换或互不重复；无意义的数字和道具不会自动形成等待。
- 效果状态：待试验

## R-章末钩子-004 用未能完成的动作显现尚待处理的后果

- 适用题材：连载 / 战斗 / 竞技
- 适用条件：胜利或脱险后仍有真实障碍，动作失败能准确呈现它。
- 可以尝试：让人物尝试一个与后果有关的动作，写清失败如何影响接下来的安排。
- 解释（推测）：动作未完成可能使新问题成为已发生的事实。
- 边界与失败方式：不限定身体故障；没有后果依据时可完整收束，不为留钩破坏已建立的胜利。
- 效果状态：待试验

## R-章末钩子-005 尝试用平常形式呈现严厉的决定

- 适用题材：职场 / 制度冲突 / 群像
- 适用条件：人物用日常程序处理重大后果，这种语气差异符合情境。
- 可以尝试：保持形式的普通与内容的具体，让受影响者的选择承接决定。
- 解释（推测）：形式与后果的反差可能突出制度运作的冷淡。
- 边界与失败方式：不保证语气越轻效果越重；愤怒、排比和直接评价也可适合本场。
- 效果状态：待试验

## R-章末钩子-006 让话语的未完成与人物处境相符

- 适用题材：死亡 / 离别 / 高潮场景
- 适用条件：人物确实因身体、情绪或情境限制而无法完整表达。
- 可以尝试：让断续影响交流，并保留读者理解关键意思需要的依据。
- 解释（推测）：表达受阻可能使未竟之事更具体，效果仍取决于关系和上下文。
- 边界与失败方式：不把省略号或短句当濒死模板；能说完时可以说完，不能因断句丢失必要信息。
- 效果状态：待试验
