# 结构：公开摘要

> 保留提炼后的条件与候选办法；原文、来源定位和真实案例留在本地。
> 所有效果均待试验。按当前文本选择，允许不用；固定数量、句式或步骤不作为质量门槛。

## R-结构-001 在需要连续性时从未完成的行动接入新章

- 适用题材：快节奏连载 / 悬疑 / 爽文
- 适用条件：上一段的行动或消息尚待回应，新章需要承接其后果。
- 可以尝试：先接人物正在做或必须处理的事，再补理解当前行动所需的前情。
- 解释（推测）：行动连续可能降低重新进入场景的负担。
- 边界与失败方式：回顾、天气和氛围并非禁用；时间跳转或新卷开篇可以采用不同入口。
- 效果状态：待试验

## R-结构-002 用可见变化帮助辨认长线进展

- 适用题材：系统流 / 娱乐圈 / 竞技 / 无限流
- 适用条件：长期目标难以被读者定位，某种变化能真实反映进展或代价。
- 可以尝试：选择与目标有关的刻度、关系或行动结果，在有实质变化时呈现并承接。
- 解释（推测）：可比较的变化可能让阶段位置更清楚。
- 边界与失败方式：不要求每章数字都动；静场、停滞或目标改向也可有价值，避免用报数代替因果。
- 效果状态：待试验

## R-结构-003 让计划的受阻与已有条件中的余地相连

- 适用题材：群像 / 冒险 / 多线
- 适用条件：分头行动存在可信阻力，人物仍有前文建立的资源或关系可调整。
- 可以尝试：写出计划依赖的条件如何失效，再让人物利用已有余地付代价补救。
- 解释（推测）：受阻与补救有前提，可能使计划既有风险又能体现应变。
- 边界与失败方式：不固定受阻次数；计划顺利也可以成立，不用临时通知或巧合包办补救。
- 效果状态：待试验

## R-结构-004 用暂时收束后的疑点重新打开冲突

- 适用题材：单元收束 / 结局前 / 悬疑
- 适用条件：阶段结果已可信落定，但一个未处理的事实足以改变其含义。
- 可以尝试：先结清已完成的部分，再由有依据的疑问改变下一步选项。
- 解释（推测）：阶段结束与新疑点的对照可能重组读者的等待。
- 边界与失败方式：不反复假结局，不取消已经兑现的后果；完整结束同样可以是合适选择。
- 效果状态：待试验

## R-结构-005 用开篇元素的再出现呈现结尾变化

- 适用题材：长篇收尾 / 呼应结构
- 适用条件：开篇元素足够清楚，重现时能与人物或局面的变化形成联系。
- 可以尝试：选择仍有意义的布景、物件或话语，让相似处与差异回应已经走过的过程。
- 解释（推测）：旧元素在新处境中出现，可能支持读者作前后对照。
- 边界与失败方式：不要求逐字照搬；全新意象或无显式呼应的结尾也可成立，避免只为闭环搬布景。
- 效果状态：待试验

## R-结构-006 用承接话语连接相邻章节的行动

- 适用题材：连载 / 悬疑 / 强承接章节
- 适用条件：上一章末句的含义尚待回应，读者需要继续这轮交流或选择。
- 可以尝试：接住末句的核心问题，直接写回应、质疑或行动；必要时短暂复现关键词。
- 解释（推测）：话语与后果连在一起，可能使翻页前后的关注保持连续。
- 边界与失败方式：不要求照抄末句或形成固定习惯；重复妨碍推进时可直接展开，新场景也可另起。
- 效果状态：待试验
