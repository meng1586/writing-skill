# 结构

> 维度：结构 · 规则数：2 · 最后更新：2026-10-21

## R-结构-001 每章开头直接写正在发生的动作，删掉回顾和天气

- 为什么：读者点开新章，最想接的是上一章那口气；开头一段「上一章我们说到」或「天阴沉沉的」，等于让读者先下车再上车。第一句就让人物继续做上一章没做完的事，追读的惯性才接得上。
- 出处：《异兽迷城》正文第 6—15 章
- 正例：每章第一句直接是人物正在做的动作或刚听到的坏消息——推门、拔刀、接电话、听见喊声，前因用一句半句补在动作后面。（第 6—15 章）
- 反例：「清晨，阳光透过窗帘洒进房间。高阳伸了个懒腰，回想起昨天发生的事……」——天气加回顾，读者要等三句才回到现场。
- 适用题材：快节奏连载 / 悬疑 / 爽文
- 适用条件：章更连载；大卷开篇需要铺氛围时可让例一次
- 关联：R-对话-002
- 状态：可用

## R-结构-002 设一个每章必须变化的可见刻度，收尾让它动一次

- 为什么：连载最怕读者不知道现在到哪了。一个可数、可看的刻度（期待值、钟声、铜钱、伤口）每章动一次，读者不用记设定也知道胜负和进度；刻度停住的一章，读者会自己觉得水。
- 出处：《我不是戏神》第 4—10 章
- 正例：陈伶的「观众期待值」每一场都变，收尾必给一次数字或反应；下一场必须回应这次变化。（第 4—10 章）
- 反例：只写「他名气越来越大了」，不落到任何数字或可看的变化——读者感觉不到进度，爽点也失去参照。
- 适用题材：系统流 / 娱乐圈 / 竞技 / 无限流
- 适用条件：需要长期连载的进度感；单元短篇可不设
- 关联：R-节奏-003
- 状态：可用
