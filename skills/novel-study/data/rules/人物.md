# 人物

> 维度：人物 · 规则数：2 · 最后更新：2026-10-21

## R-人物-001 出场只给一个动作加一句台词，履历拆到后文三次交代

- 为什么：读者记人靠动作和声音，不靠户口本。一次把前史倒完，人物就变成会走路的设定卡；留白反而让读者追着问「这人是谁」。
- 出处：《异兽迷城》第 1—5 章（正文第 1—5 章）
- 正例：高阳出场时只写他接电话、躲王子凯抢手机、改口约李薇薇，前史「六岁穿越、五口之家」拆到早饭和独处时才补。（第 1—2 章）
- 反例：开篇先写「高阳，十八岁，十二年前穿越到平行世界，父母是……」，把三条设定一次倒完——读者三句内没有动作可跟，人物先变成说明书。
- 适用题材：都市 / 悬疑 / 玄幻 / 快节奏开篇
- 适用条件：配角第一次出场也照此办理；需要交代身份时，让动作带出来（摸钥匙、找水、报平安）
- 关联：R-结构-001
- 状态：可用

## R-人物-002 给每个家庭成员一个重复的生活动作，让秘密从动作里漏出来

- 为什么：家庭戏的恐怖不在于谁说漏嘴，而在于每个人都在做「还是那个家」的动作，动作却对不上。重复三次之后，读者自己会发现不对，参与感比旁白解释强十倍。
- 出处：《我不是戏神》第 21—30 章
- 正例：父母照常摆碗筷、问冷暖、留灯，可每一轮的停顿、眼神和那句「昨晚已经杀死了阿伶」一起漏出真相。（第 21—24 章）
- 反例：让父母直接对陈伶说「其实你不是我儿子」——把秘密交给台词，动作线就废了，读者只能被动听解释。
- 适用题材：悬疑 / 民俗恐怖 / 家庭伦理
- 适用条件：需要写「日常里藏异常」；纯动作爽文不适用
- 关联：R-语言-002
- 状态：可用
