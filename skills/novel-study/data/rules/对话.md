# 对话：公开摘要

> 保留提炼后的条件与候选办法；原文、来源定位和真实案例留在本地。
> 所有效果均待试验。按当前文本选择，允许不用；固定数量、句式或步骤不作为质量门槛。

## R-对话-001 让关键问句承载关系中的多层含义

- 适用题材：悬疑 / 情感 / 复仇
- 适用条件：同一事实同时引发确认、责问或不愿相信，语境已提供理解依据。
- 可以尝试：围绕人物真正想确认的事组织问句，让回应、停顿与后续选择展开其余含义。
- 解释（推测）：多层语用可能使台词同时推进事实与关系。
- 边界与失败方式：不要求每句都含潜台词；信息不足时直说更清楚，省略号本身不产生复杂情绪。
- 效果状态：待试验

## R-对话-002 把必要解释放进有行动目标的交流

- 适用题材：系统流 / 无限流 / 都市异能
- 适用条件：人物确实需要信息，而正在做的事能使提问与回答有后果。
- 可以尝试：围绕当前决定组织问答，让行动、异议或新情况决定何时继续和中断。
- 解释（推测）：信息参与决策，可能使说明与场景推进相连。
- 边界与失败方式：不规定问句数量或必须打断；需要完整说明时可讲清，不为挂动作制造无关麻烦。
- 效果状态：待试验

## R-对话-003 用有动机的改口呈现未能直说的内容

- 适用题材：悬疑 / 对峙 / 群像
- 适用条件：人物有不能直说的理由，读者有足够线索理解改口的分量。
- 可以尝试：让话语朝一个方向开始，再因具体顾虑转向另一个表达，并写出互动后果。
- 解释（推测）：表达的差异可能暴露犹豫、隐瞒或自我保护。
- 边界与失败方式：心理描写可以帮助理解；缺少可读依据时不宜只留谜语，也不把断句当效果保证。
- 效果状态：待试验

## R-对话-004 在双方能推知后果时保留部分话外信息

- 适用题材：智斗 / 悬疑 / 对立者交流
- 适用条件：双方共享关键知识，说出一部分已足以改变对方选择。
- 可以尝试：明确已说的条件与未说的后果，让对手的回应显示他推知了什么。
- 解释（推测）：留白可能让施压通过对方判断发生，而非只靠宣告。
- 边界与失败方式：不固定省略步数；读者缺必要知识或人物应解释时，应补足而非装作高深。
- 效果状态：待试验

## R-对话-005 让点破与提供出路形成复杂的邀请

- 适用题材：群像 / 复仇 / 复杂对立关系
- 适用条件：说话者既看见对方弱处，又有理由希望其改变选择。
- 可以尝试：把揭穿与可接受的下一步放在同一轮交流中，保留对方拒绝或反击的可能。
- 解释（推测）：攻击与理解并存，可能使双方关系难以被单一态度概括。
- 边界与失败方式：不把羞辱当共情的必要步骤；对白和动作都可承载态度，避免替人物预定被说服。
- 效果状态：待试验

## R-对话-006 用具体生活语言调整抽象争论的层次

- 适用题材：思辨 / 群像 / 长篇
- 适用条件：争论较抽象，需要看见它与眼前人物、生活或选择的联系。
- 可以尝试：让人物用符合其身份的具体问题、口语或日常关注回应论题。
- 解释（推测）：从概念回到处境，可能帮助读者理解争论的实际分量。
- 边界与失败方式：不按段数强插笑话；抽象辩论可以持续，日常话也不必只负责缓和气氛。
- 效果状态：待试验
