# 本地阅读笔记模板

先记录阅读反应，再拆解文本，最后提出可试的写作假设。这个顺序帮助区分观察与解释；不要求所有维度填满，也不靠术语是否出现判定“真读过”。

具体原文、书名章号、完整案例和阅读记录保存在本地。公开摘要另按 [规则格式](rules-guide.md) 整理，保留原编号、条件与边界。

## 0. 对象、范围与目标

- 材料名称与本地定位：
- 本次读了什么范围，必要前情是什么：
- 想解决的学习问题：
- 当前判断：keep / watch / drop，理由：

选材思路见 [选书标准](选书标准.md)。判断仅覆盖本次目标与阅读范围。

## 1. 阅读反应

- 这一段发生了什么（简短梗概）：
- 哪个具体位置让我停下，反应或疑问是什么：
- 反应来自模型判断、作者自检还是真人反馈：
- 我是否需要补足前文或后果才能判断：

模型的反应是待核实的判断，不等于独立真人反馈。

## 2. 文本拆解（按需选择）

| 维度 | 可追问的问题 |
|---|---|
| 开篇 | 读者何时知道人物处境、当前问题与值得等待的结果？ |
| 节奏 | 信息、行动、关系和结果怎样分布？哪些变化来自前文？ |
| 人物 | 人物想得到、害怕失去什么，选择和关系怎样改变？ |
| 对话 | 这句回应在争取什么，信息与人物关系是否同时变化？ |
| 章末 | 如何收束当前一段，留下了什么等待或情绪余波？ |
| 语言 | 句法、词语、标点、感官和视角怎样服务当前表达？ |
| 结构 | 单元或卷的结果怎样改变后一段的选项？ |
| 情绪 | 关切、已知信息、人物选择与情绪变化之间可能有什么联系？ |

每个保留的观察分开写：

- **文本事实**：本地可核对的具体位置与内容：
- **效果解释（推测）**：可能怎样起作用；还有什么解释：
- **边界**：是否依赖人物、前情、视角或读者已有信息：

语言统计用于描述差异，不以句长、比喻数量或段落长度直接判定质量。宏观问题可参考 [卷纲模板](卷纲模板.md)。

## 3. 可试的写作假设

- 候选动作：
- 什么条件下值得试：
- 为什么值得试（推测，可空）：
- 什么情况下可能不适合：
- 怎样比较本次试写与原稿：
- 当前试用状态：待试验 / 已试用 / 有条件支持 / 暂不采用 / 看不出差别：
- 反馈类型与范围：模型推断 / 作者自检 / 真人反馈（注明具体条件）：

一位读者只算一例；没有反馈就写未测。证据覆盖和试用状态分开，不把跨书出现升级为效果已验证。

## 4. 批评与未覆盖项

有具体问题时记录位置、现象、语境和其他可能解释；没有发现可以留空。不要为凑数量制造批评，也不把一次局部问题推广成固定篇幅禁令。

## 5. 下一步

- 继续阅读、试写、补语境、暂不采用或没有待办：
- 新增摘要编号与本地证据的对应关系：

旧笔记和已有进度不因换模板批量重写；新模板用于后续新记录。
