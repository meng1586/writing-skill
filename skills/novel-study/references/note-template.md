# 单本阅读笔记模板（三层阅读法）

> 为什么分三层：只拆元素，读出来的是别人的骨架；只谈感受，学不到能落笔的东西。
> 先当读者，再当拆解者，最后当作者。**顺序不能换。**

# 《书名》阅读笔记

## 0. 这本书值不值得学

> 这一节决定后面值不值得花时间。判断标准见 `选书标准.md`。

- 平台数据：在读 / 评分 / 月票 / 完结状态 / 实体出版或获奖
- 口碑：书评区、豆瓣、知乎里的正反评价各一条
- 前 3 章判断：有没有让我停下来的句子？有没有我写不出来的东西？
- 评级：★☆☆☆☆（1–5）
- 结论：keep / watch / drop
- 一句话理由：

## 1. 读者层：我读到了什么

> **这一层只许写感受、疑问、共鸣。**
> 不许出现「节奏」「钩子」「人设」「爽点」「伏笔」这类分析词——那些留给第 2 节。
> 目的：先诚实地当一个读者，否则后面拆出来的全是套路，没有体温。
> 模型填写的是可定位、待核实的阅读判断，不是独立真人反馈。不能仅凭禁用了分析词就声称已验证效果。

- **这一段大概讲了什么**（3–5 句，只讲发生了什么，不加判断、不夸不贬；写完自己读一遍，能看明白才算数）：
- 最直接的感受（一个词或一句话）：
- 哪一段让我停下来，为什么：
- 我有什么疑问（人物为什么这样选？作者为什么这样写？）：
- 这里让我想起了什么（自己的生活、别的书、别的人）：
- 作为读者，我会追下去吗？为什么：
- 有没有哪一句，我想抄下来发给别人：

## 2. 拆解层：作者怎么做到的

> 每个维度要回答「**怎么做到的**」，不是「**有什么**」。
> **但不必每篇都填满**：没变化的维度写「无变化」，没有新东西的维度可以跳过。
> 这是笔记，不是作业——**没有值得记的，就少写。**
> 写「有悬念」是废话；写「把答案拆成三份，每章末给一份」才是拆解。

### 2.1 开篇（前 3 章怎么留人）
- 第一句在干什么：
- 前 3 章各抛了什么新问题：
- 让读者「必须翻下一章」的那个东西是：

### 2.2 爽点与节奏
- 爽点类型（打脸/获得/装逼/情感/解谜/信息占先）：
- 第几章给、间隔几章、每次给多大：
- 有没有「预期爽点」（读者先于配角知道主角要赢）：

### 2.3 人物与关系
- 主角的欲望与恐惧：
- 每个配角承担的**功能**（不是性格，是功能）：
- 关系是怎么被绑死的（利益/秘密/亏欠/共同的敌人）：

### 2.4 对话
- 对话在推进什么（信息/关系/冲突/人设）：
- 谁的话最少、信息最多：
- 有没有「说话方式本身就是证据」的设计：

### 2.5 章末钩子
- 每章末句类型：解释性反转 / 身份反转 / 主角决断 / 新威胁 / 倒计时
- 有没有连续用同一种（*有些读者会疲劳，但不是必然；这只是一个观察点*）：

### 2.6 结构
- 单元怎么切（一个游戏/一个案子/一个秘境）：
- 卷目标与单元目标的关系：
- 需要讨论卷级或完整冲突时，参照[卷纲模板](卷纲模板.md)的承诺、选择与代价、局面变化、回应与承接；按自然转折记，不要求每单元填满四格。

### 2.7 语言指纹

> 不是「语言好不好」，是「它的语言长什么样」。写到能照着模仿、能对照自查的程度。

- **句长与节奏**：平均一句多少字？短句怎么用（钉节奏/打断/收束）？长句出现在哪里？
- **标点习惯**：破折号、省略号、感叹号、问号的使用密度；有没有独特的标点癖好。
- **用词**：名词具体还是抽象？动词密度高不高？形容词多少？方言/脏话/行业术语/成语的使用。
- **比喻取材**：从哪来（自然/器物/身体/城市/绘画）？是钉节奏的短比喻，还是敢展开的长比喻？一章用几次？
- **感官配比**：视觉/听觉/嗅觉/触觉各占多少？紧张或恐惧落在哪一感？
- **对话语言**：每个角色的口癖、语气词、打断与抢话、称呼；谁的话最少、信息最多。
- **叙述视角**：第几人称？限知还是全知？镜头贴着谁走？会不会切别人的内心？
- **描写配比**：动作/心理/环境/对话，大概几比几。
- **去 AI 味对照**：具体避开了哪些（套话、成串比喻、抒情长段、每段总结、人物一个腔调），列出来，能拿去对照自己的稿子。

### 2.8 风格指纹（味道）

> 这一节是给「写」用的：如果你要模仿它，先看这里。

- **一句话味道**（说出它读起来像什么，不许用「好看」「精彩」「带感」）：
- **3–5 句锚点原句**（最能代表这本书的，标章号；不是最激烈的，是最「像它」的）：
- **要模仿它，先做到的三件事**（每条动词开头）：
- **它独有的、学不来的东西**（写清楚，防止自己硬学学到变形）：

### 2.9 批评：这一单元哪里可以更好

> 有具体问题就记录；未发现或当前范围未覆盖可如实写，不为凑数制造批评。
> 写成「作者不行」没用，要翻译成「下次我不这么写」。

- 哪一章哪一段：
- 问题是什么（设定崩 / 人物假 / 节奏拖 / 对话假 / 作者偷懒 / 逻辑硬伤）：
- 翻译成一句写作教训：

### 2.10 情绪试验卡（可选，想验证某场情绪时填一张）

> 不是每单元必填。只在你想验证「这场为什么会让人心疼/想哭/紧张」时填。
> 先标「候选路径」，不标「必要步骤」——一条路径失效，这个情绪可能换别的路成立。
> 只用于未写单元；不重写或迁移已完成的笔记及正式副本。选择办法时参照[情绪的表达问题与条件选择](../data/rules/情绪.md)，不按情绪名称套卡。

- **关切对象与依据**：人 / 事（真相、公平）/ 关系（可多选）；读者为什么可能在意，也可在本场形成关切
- **人物与读者的认知**：人物知道、相信并能做什么；读者已知什么，分别写清
- **关键线索与判断**：第X章某句或动作 → 据此推测读者怎样判断（确认/加深/改变/复杂化；无依据就写「机理假设」）
- **预期情绪变化**：预计发生什么、依据在哪；不要求每场改判
- **候选动作**：本场先做什么、为什么适合当前缺口、什么情况应调整
- **反例**：这条路径失效的情形（至少一条，如「人物异常冷静反而更贴」）
- **验证状态**：未测 / 模型推断 / 作者自检 / 单读者信号（一位读者只算一例）
- **真人反馈**：原话 / 从哪句开始（起始句无法定位可留空；没有真人读过，本栏写「未测」，不覆盖上栏的模型推断或作者自检）

## 3. 写作层：我能带走什么

> 这一节是给「写」用的。写不出动作的，不算带走。

- **我能落笔的技法（0–3 条，没有就写「本单元没有」）**
  （每条动词开头、能直接照做；凑不够三条就不凑）：
  1.
  2.
  3.
- **我写不出来的 1 句**（原文摘抄，标章号，说明为什么写不出来）：
- **我下次写作要试的一件事**：
- **这本书的「味道」**（一句话，说它读起来像什么，不许用「好看」）：
