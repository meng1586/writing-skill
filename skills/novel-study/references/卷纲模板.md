# 卷纲模板：完整冲突与宏观结构

借用 Sanderson 的“承诺—进展—兑现”作为提问视角，检查读者在等待什么、等待怎样变化、得到了什么回应；不把它当作每章必交的指标。

## 四个问题（按当前需要选择）

1. 读者可能在等什么：真相、关系、选择、成长或其他结果？
2. 人物作了什么选择，付出什么代价？
3. 局面具体哪里改变了：信息、关系、能力、目标或可行选项？
4. 当前冲突回应了什么，结果如何改变下一段的选项？

这些问题可用于一段完整冲突、一卷或全书；只记录与本次判断相关的内容，不要求每章、每单元四格齐全。

## 自然转折表

| 位置 | 转折 | 改变了什么 | 后续怎样承接 |
|---|---|---|---|
| | | | |

按真正改变局面的转折记录，不固定节点数。静场、关系建立或对旧事的新理解也可能有进展；需要结合前后文判断。

## 可借的框架

| 框架 | 可用来问什么 | 边界 |
|---|---|---|
| Save the Cat | 某个常见节拍在这里承担什么作用 | 不要求所有故事踩同样的位置 |
| 英雄之旅 | 离开、经历、返回中发生了什么变化 | 不要求每个故事走完一圈 |
| 开篇样本分析 | 读者何时获得本故事的等待与人物问题 | 不能代替卷间因果和全书回应 |

这些是分析与创作工具，不是效果已验证的定律。可以先选一段有起因、转折和结果的完整冲突试用，记录哪些问题有帮助、哪些不适合；留空本身不说明作品有缺陷。
