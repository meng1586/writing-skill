# 改稿后的回读检查

候选技法只处理局部问题，改完还要看人物、设定和上下文是否成立。

## 四个问题

1. **设定一致性**：新动作或台词，是否要求人物拥有他此刻没有的信息、能力或物品？
2. **前后文连贯**：把改动处与必要前文、后续放在一起读，因果和状态是否接得上？
3. **人物声音**：这句话是否符合人物此刻的目标、经历、关系和说话习惯？职业或身份本身不足以禁止一种表达。
4. **整段调子**：语体变化是否有场景依据？长短句或抒情程度变化本身不等于出戏。

可先局部试改，再比较两版；试验范围不等于正式改稿的固定限额。

## 独立虚构情境（仅演示检查方式，效果未验证）

设定为“铜铃只有遇到盐水才会响”。新稿让角色在干燥密室中摇响铜铃，且未交代其他条件。这里需要核对设定或补足条件，不能只因新句更生动就保留。

这个例子与任何现有项目无关；公开说明不沿用项目正文或角色进行改名演示。

## 一个小的试改流程

明确问题与目标 → 选择一个候选动作 → 试改 → 回读必要语境 → 比较效果和新问题 → 决定保留、调整或撤回。

记录“改了什么、在什么条件下、发现了什么”，允许结论是两版差不多或这次未解决问题。外表镇定与身体反应可以共存，不能仅按某个词判定人物前后矛盾。
