# 改稿自检（防「链路僵硬」）

> 用规则改稿最大的风险：**局部变生动，整体变不连贯。**
> 规则只看一句话，作者要看一整章。改完必须回读。

## 四道回读检查

### 1. 设定一致性（最致命）

**改动的动作/台词，违反这本书的设定吗？**

- 例：本鲸在《存档点》加了「可她是谁来着？」，但设定里主角是**唯一完整记得**的人——他不该忘。这是硬伤。
- 查法：把改动句单独拎出来，问「按设定，人物此刻能不能做出这个反应？」
- 改法：改成符合设定的版本（「想递给谁，手停住」——他记得，但她不在了）

### 2. 前后文连贯

**上一句、下一句还接得上吗？**

- 查法：把改动处前后各读三句，中间抽掉新句，看是否通顺；再插上新句，看是否突兀。
- 常见断裂：前文说他「冷静」，改后让他「失控地手抖」——若没有铺垫，读者会觉得跳。**注意：外表镇定和身体反应可以共存**，不是一出现手抖就算矛盾，要看有没有给读者过渡。

### 3. 人物声音

**改后的句子，像不像这个人说话？**

- 例：卡车司机林越不会说「我感到一阵难以言喻的悲恸」。
- 查法：把改后的句子读出声，问「他会不会这么说话？」

### 4. 整章调子

**改后和整章的气氛一致吗？**

- 例：整章是短句、粗粝、第一人称，改后突然一段文艺长句，读者会出戏。
- 查法：把改后的段落和原稿相邻段落并排读，看语感是否打架。

## 改稿流程（别跳步）

```
1. 诊断（这一场缺什么）
2. 选规则（哪条对得上）
3. 改一处（**这是试验范围**，不是所有改稿都只能改一句；正式改稿可以改多处，但每处都要过四查）
4. 回读四查（设定/连贯/声音/调子）
5. 不通就退回去，不要硬留
6. 记下：改了哪句、为什么、回读发现什么
```

## 关键认知

**规则是局部的，作品是整体的。**
规则能告诉你怎么让一句话更疼，但它不知道这句话会不会毁掉人物的设定、上一段的伏笔、或者整章的语感。

**改完不回读，等于没改。**
