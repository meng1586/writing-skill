# 候选技法与案例格式

位置：`skills/novel-study/data/rules/{维度}.md`；`plan.py --sync` 将确需发布的规则同步到 `06-素材/读/规则/`。

## 区分三件事

- **原文事实**：作者在这里写了什么；提供书名、章号及可核对的片段。缺原文就标待核对，不把概括冒充摘句。
- **效果解释**：推测它在该语境产生什么阅读效果，指出依据和其他解释。
- **写作假设**：当前场景的表达问题是什么、什么条件下先试什么办法、预期改变什么、何时应调整。

有出处不等于效果已验证。模型推断、作者自检和真人反馈分别说明；一次真人反馈只是一例。案例只说明某处用过某种写法，不直接升级成跨背景规则。

## 新卡格式

按已有维度存放；确有需要再增维度，调用器会发现新增 `.md`。没有本场缺口就不必新增卡，也不为凑数补例子。

```markdown
## C-014 用身体动作呈现控制正在失效

- 类型：候选技法
- 原文事实：《示例》第1章，具体片段及其上下文（尚未取得就标待核对）
- 效果解释（推测）：读者可能从违背人物意愿的动作读到失控
- 写作假设：人物想维持镇定、控制却开始失效，且视角允许呈现时，可尝试
- 适用条件：已有维持镇定的依据；本场缺少能显示失控的选择或动作
- 候选动作：先试一个与人物意愿冲突的动作，检查是否比现有说明更清楚
- 调整条件：异常平静本身才是重点时，不强加手抖；若只是重复已有信息就删去
- 适用题材：通用；依据本场条件选择
- 状态：待试验
```

使用 `## C-编号 标题` 或 `### C-编号 标题`。旧 `##/### R-维度-编号 标题` 继续支持，不重编旧卡；修改抽象方法不改旧笔记。调用器保留正文、出处、条件、状态和来源文件。卡片标题写成无标记的 `C-014 ...` 等错误格式时会报错，不静默丢弃。

## 条件与状态

题材标签只用于查找；它不能替代人物处境、读者已知信息、关系与利害、叙述视角和当前缺口。可以明确建议“先做 X，因为 Y，预期 Z；若 W 就调整”，不必把不确定性写成反复免责声明。

当前候选状态使用：待试验 / 在某些条件下有帮助 / 暂不采用 / 看不出区别。帮助仅限记录中的条件与证据；不设固定次数的升级或淘汰门槛。

- 旧“可用/待验证”仅是入库标签，调用时按“待试验”显示并保留原标签。
- 旧“已淘汰”以及“暂不采用”保留记录和原因，调用器跳过，不删除出处。
- 没有状态的新卡默认待试验；“看不出区别”不改称有效。
- 若同一办法跨多个背景仍被推荐，检查背景是否改变了适用条件及理由；不能按“换三个背景”自动淘汰。
- 原文观察和抽象结论分开维护：泛化缺少支持，先收窄边界或标待验证，不抹去案例证据。

## 笔记与候选卡的边界

笔记记录某次阅读的覆盖范围与理解；候选卡供后续写作选择。新方法只用于未写单元，不迁移、重写已完成笔记及正式副本。候选卡可按新证据调整条件，保留旧编号和来源；合并真正重复的内容时注明关联，不以卡片数量作为质量指标。
