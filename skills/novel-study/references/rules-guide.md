# 规则摘要格式

规则摘要帮助写作时判断“什么条件下值得试哪一步”。它保留提炼后的描述，不随包附带具体原文和来源定位。原编号用于回查本地完整版，不因公开整理重编号。

## 文件与格式

位置：`skills/novel-study/data/rules/{维度}.md`。维度包括开篇、节奏、人物、对话、章末钩子、语言、结构和情绪；分类只是检索入口，不要求一场戏用齐。

```markdown
## R-维度-编号 一句话总结

- **适用题材**：具体题材，或通用及必要的排除条件
- **适用条件**：本场目标、人物状态、视角和需要的前文信息
- **可以尝试**：一个或少量可执行的候选动作
- **为什么值得试（推测）**：可选；解释可能的作用，不把比较效果写成定论
- **边界**：什么时候可能不适用，需要检查什么
- **效果状态**：待试验
```

标题以 `## R-` 或 `### R-` 开头。解析器接受加粗或不加粗的“适用题材”，以及“状态／效果状态／试用状态”；公开模板统一使用上面的字段写法。题材用于检索，适用条件用于人工判断，两者不互相替代。

## 两种证据问题

- **来源覆盖**：阅读材料中出现过多少相关观察；完整证据和定位留本地。
- **试用状态**：是否实际用于写作、在什么条件下得到什么反馈。

更多阅读案例只扩大文本观察范围，不自动证明迁移有效。公开摘要从待试验起步；确有试用反馈时，说明条件和证据范围，再决定如何调整。

## 本地与公开的分工

本地完整版可保留原文事实、来源、完整案例、效果解释和试写记录。导出公开副本时保留条件、动作和边界，去掉具体原文与来源字段；不把改名后的旧案例标成原创虚构。

独立的格式演示见包根目录 `examples/`。模板只说明字段，不要求为填满字段补造案例。

## 维护

- 原编号保持稳定；真正相同的条目可合并并保留旧编号指路。
- 淘汰条目保留编号和原因，使用“已淘汰”或工具支持的相应状态，不再推荐。
- 不用固定次数决定规则有效或失效，不因没有新结论重写旧笔记。
- `plan.py --sync` 根据 `config.json` 同步到包根目录的 `06-素材/读/规则/`。
