# 阅读反馈与事实校对模板

两个角色回答不同问题。模型反馈用于发现值得复查的位置，不当作真人读者效果，也不按分数直接决定删改。

## 阅读条件先说清

- 测试首次接触时，明确只读当前片段，并把结论限定为这种条件。
- 测试连载中的阅读时，提供读者本应知道的前文或事实摘要；缺少必要前情不能直接算章节缺陷。
- 实际读过正文的范围、作者自检、模型推断和真人反馈分别记录。不同条件下的评分不要直接相加比较。

## 一、阅读反馈

可用于开篇、转折、改稿后复查，按当前疑问选择；无需每章固定派若干代理。先核对具体句子和理由，再决定是否改稿。记不住角色或一次出戏，也可能来自阅读范围、任务方式或口味差异。

```text
请从当前目标读者的阅读条件出发，反馈下面这段文字。不要声称自己是真人读者，也不要把推测写成已测效果。

本次阅读条件：{首次接触／已读过哪些前文}
本次想检查的问题：{一个具体问题，可留空}
必要前文：{只给实际已知事实，避免透露尚未读到的后续}
正文：
{粘贴正文，标明范围}

请回答：
1. 读完后最想继续知道什么，或暂时没有什么等待？指出相关句子。
2. 有没有让理解中断、反应不连贯或产生疑问的位置？引用具体句子，说明当时缺少什么。
3. 哪个人物或关系不容易区分？说明是文本本身的信息不足，还是本次未提供相关前文，拿不准则写待确认。

没有发现可以写“未发现”。只描述这个阅读条件下的判断，不预测普遍读者反应，不为了填满答案编问题；先反馈现象，不直接替作者决定删人或重写。
```

## 二、事实校对

提供正文、相关人物与世界规则、时间线及必要前文。大纲中尚未发生的计划与正文事实要分开标明。

```text
请校对正文中的因果、设定和时间线，只列有具体对照依据的问题，不评价文笔或情绪是否“够强”。

已生效的设定与前文事实：
{人物、规则、时间线及相关原文}

尚未发生的写作计划（如有）：
{与已发生事实分开}

待查正文：
{粘贴正文并标明范围}

每条问题写：
- 位置与原句
- 对照依据
- 具体冲突或因果缺口
- 影响：影响理解／影响可信度／轻微问题
- 确定程度：明确矛盾／需要作者确认

找不到对照依据时不要硬判；没有发现就写“未发现”，说明核对范围。相同矛盾合并报告，不为凑数量重复列项。
```

## 三、怎样使用结果

1. 核对引句和对照材料是否真实存在。
2. 将问题与本场目标、人物状态、必要前情一起判断。
3. 必要时小范围试改并回读，允许维持原稿。
4. 记录实际采用的候选、修改位置、条件与反馈来源。

读者视角可能发现困惑，事实校对可能确认硬伤；两者不能互相替代。模型判断、作者自检和真人反馈都不要只用一个总分代替具体观察。

回填命令见 [writing-loop](../SKILL.md)。程序的 `--verdict` 是这次使用记录中的评价，`--compared` 标记是否确实做过对照；不要为升级状态而填写并未进行的实验。
