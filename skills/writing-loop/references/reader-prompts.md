# 阅读反应与一致性检查

两种检查回答不同问题，按任务选择。模型能提供待核对的阅读解释和矛盾线索，不能替代真人的实际阅读反馈；换模型或多派代理也不会变成真人样本。

## 阅读反应检查

材料包括当前章，以及目标读者实际已读的前文。可按需要给原文或有出处的事实摘要，并说明摘要的限制；不要给后续大纲、作者意图或预期情绪答案。若专门测陌生读者能否从中途进入，要说明这是另一种阅读条件，不能据此把所有依赖前文的章节判为有问题。

模型代理可用以下提示：

```text
请基于所给已读前文与当前章，检查阅读时可能形成的理解。
输出须标为“模型推演”，不要扮成真实读者已经发生的感受。

- 当前章最先可能引出的感受或念头是什么？允许没有明显反应。
- 哪句或哪个动作支持这个判断？指出位置，不能定位就说明。
- 读完后有什么尚不明白或想继续知道的事？缺失前文与文本本身矛盾分开写。

不要猜作者预设答案，不为填满格式编反应，不把自己的推演直接当改稿命令。

已读前文（注明章号、原文/摘要及版本）：
{已读前文}

当前章（注明章号及版本）：
{当前章正文}
```

真人试读先保存作者预期，阅读前不展示答案；读后可轻问：“最先有什么感受或念头？”“从哪一句开始？”没有感受、找不到位置都可以。保存真人原话，不用模型替读者补答案。一位读者只提供这一例的信号；若比较两稿，记录阅读顺序及条件，并允许两版差不多或都不合适。

## 一致性检查

给当前正文、必要前文，以及已定人物、世界规则、物品和时间线。资料注明来源及版本；区分已写事实、作者确定的约束与尚未发生的规划，不把后续计划当成正文已经发生的事。不必给作者希望审阅者找到的问题或阅读反应检查的结论。

```text
请检查本章与所给已定事实的冲突、因果断链和时间线问题。
每条线索说明：本章位置及短引文、对照材料位置及依据、两者为何冲突、可能影响。
拿不准或材料缺失时标“待确认”，不要为交差猜设定，也不以个人文风偏好判断硬伤。
未发现问题时说明核对了什么及缺少什么；结论只覆盖所给材料。

已定事实/设定及必要前文（注明来源及版本）：
{事实与设定}

当前正文（注明章号及版本）：
{当前正文}
```

## 使用结果

先核对被指出的位置，再区分事实矛盾、理解差异与个人偏好，结合作者目标决定是否改。不能按随机分数、连续几次低分、代理票数或某种句式直接判作品质量；人物是否保留、句子是否删除也不能只由代理意见决定。

阅读模型评审用 writeback.py add --reviewer-type model；作者自检用 author。只有真人反馈才用 reader，效果状态还须有两稿版本、反馈引用、适用条件、明确比较结果及记录者确认，详见 [../SKILL.md](../SKILL.md)。证据不足时保留普通使用记录，继续正常写作。
