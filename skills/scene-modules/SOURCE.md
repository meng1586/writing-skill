## 自测（2026-10-20，Python 3.11.4）

| 命令 | 结果 |
|---|---|
| `python3 scripts/query.py --list` | 列出 12 张卡，按「打脸→反转→告别→……」固定顺序 |
| `python3 scripts/query.py --type 打脸` | 输出完整卡片（适用/结构/正例/崩法/变体/自检） |
| `python3 scripts/query.py --type 告别` | 输出完整卡片（含 3 个正例） |
| `python3 scripts/query.py --type 诀别` | 别名命中「告别」卡片 |
| `python3 scripts/query.py --search 倒叙` | 命中「告别」3 行（L22/L29/L32） |
| `python3 scripts/query.py --type 告别 --json` | 输出合法 JSON（type/summary/aliases/path/content） |
| `python3 scripts/query.py --type 蒙太奇` | 退出码 1，提示未找到并列出全部可用模块 |
