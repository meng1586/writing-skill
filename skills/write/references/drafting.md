# 起草与接续

## 准备到可以写

先读作者要求、相关规划和相邻正文。明确叙述者/视角、语气、时间位置、本次范围与不可改内容；不必补齐整个世界档案。作者只给念头时，按长短篇分支形成足够起草的规划；已有细纲则核对其中的关键方案是否已选，接着实际进度处理。

开写前核对本次范围内的关键剧情是否已讨论选定；未选时先按 `methods.md` 交付方案与取舍，停在方案阶段。作者要求最终成稿不能代替选择；已有明确方案或明确的本轮代选委托则直接继续。

## 根据主题确定或沿用文风

先看本作在探索什么处境、矛盾或关系，以及作者希望读者怎样经历它；主题可以暂定，随故事发展再核对，不强造明确寓意或把正文写成主题说明。题材不能直接决定文风，同一主题也可以有不同的成立写法。

作者未定文风时，结合叙述者与视角、人物的经验和处境、故事规模及希望的阅读体验，选择适合的表达取向。按需考虑语域与语气、叙述距离、句式与节奏、心理/行动/对话的展开、详略与意象使用；在已有规划或本轮交付中简记采用什么、为何适合及主要取舍，不另建风格表，也不要求逐项填写。以具体人物与阅读效果判断，不固定短句、冷硬、抒情或心理描写比例，不把“更文艺”当作更适合。

作者已有明确文风或现稿已有稳定声线时直接沿用，续写先读相邻正文，不借重新解释主题擅自换风格。未定且没有实质分歧时，自行选用合适取向并继续；差异会显著改变整篇体验时才给出少量可比较的取向、理由与代价，沿用作者的选择或本轮代选委托。必要时可提出同一情境的短段试写供比较，但作者要求先选剧情再写时，不提前试写；也不能为试文风越过尚未选定的关键剧情。文风与剧情已经明确时正常继续，不设置逐章或逐场的例行批准点。

主题、预期体验与文风意图是创作与编辑材料，只给主笔、内部编辑或总编辑 B 第二轮；不提前交给独立冷读 A 或 B 第一轮，不用“主题已表达”代替实际阅读反馈。

## 连续成稿

顺着人物当时知道的事写观察、心理、行动和对话，让选择与后果在场景里发生。不要把大纲条目扩写成一串主题说明，也不因追求留白删去必要的心理与生活细节。

按已选方案完成有连续经验的正文，不必边写边展示卡片步骤。遇到明确困难，如动机不成立、信息揭示太早、对话只在传递资料，可回看 `methods.md`；允许选不到、选了不用，或发现已有写法更合适。若新发现需要改变作者已选的关键剧情，说明原因与新取舍，先讨论受影响部分；常规细节调整直接完成。

安静场景也可充分展开。细节不必个个成为象征或伏笔。检查读者是否已经能理解，再决定要不要解释：保留新信息、人物独特理解和必要心理；删去的对象是重复告知与预先替读者下结论，不是一切议论。

按用户要求写完整故事、章节或片段。长稿受单次上下文或输出限制时在自然位置接续，准确说明完成到哪里；不能把提纲或省略号称为已完成正文。不要为强凑字数重复冲突。

## 最小接续材料

短篇通常只需规划与正文。长篇在现有规划文件中短记：实际写到哪里、会影响下文的新事实、仍未解决的后果与下一步。人物资源、知情、伤病、日期、物件等，只记本作容易出错且后续会用到的部分。

明确标识“已写事实 / 计划 / 未定”。不用同一信息维护多份台账；无须每章填全人物卡和场景卡。续写先检查相关实际状态，不把未来细纲当回忆。

接续或交接时，在现有规划或交付说明中保留：唯一当前正文路径与版本、实际完成范围、已选/待定的关键方案、本轮修改及实际复查范围。依据实际文件和已选内容接着写，不因换了对话重做全部构思，也不把旧版审读结论直接当成新版已验。

## 交接审读

标明当前版本、完成范围和作者关心的问题。文学首读只看正文和必要的中性题材说明，不给预期情绪、标准答案或幕后计划。作者视角和编辑视角再结合原定目标判断取舍，方法见 `editorial.md`。
