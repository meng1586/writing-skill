# 长篇：全书方向 → 当前卷 → 近章细纲

直接使用已有设定和正文。从作者要求的规划层级接入，不为了写近章重新生成整个世界。这里的层级用于控制远近细节，不是每次必须完成的三张表。

## 构思：能持续产生不同选择

明确人物想得到或守住什么，为什么现在必须行动，阻碍来自什么人、条件或规则，他有什么选择以及各自的代价。代价包括资源、关系、机会与自我认识，不必持续升级死亡和灾难。读者可以追随关系、事业、生活经验或问题，无须给每个题材增加反派。

检验核心设定能否产生不同处境、选择和后果；不断更换更强敌人、重复同一种解决办法，不足以支撑长篇。作者已定的核心关系、文风与终局是约束；尚未定案的内容保留为假设。

## 全书：远粗近细

用简短概况或阶段表说明主问题、人物起止状态、关键转向和可能的终局。远期只写功能、重要事件、需要保留的空间与待定问题；不提前编满全书章号。终局可保留候选，但不能把猜想写成事实。

记住开篇建立的期待，安排逐步进展与阶段答案。悬疑、能力边界、关系结果分别控制揭示；既不能提前泄底，也不能把所有进展无限延期。这里的“承诺—进展—兑现”用于核对读者正在等待什么，节点随实际转向形成，不规定数量。

## 当前卷：围绕一次有后果的变化

先说明入口状态、当前目标、主要阻碍、关键选择与结束状态，再逆推必要事件。按实际需要拆成有因果联系的剧情单元，可用连贯文字写：承接的期待 → 尝试与受阻 → 选择与行动 → 结果及收益归属 → 代价或余波 → 引向下一单元的条件。

不是每个单元都要填齐同样的栏目。关系、局势、认知或生活状态的变化都可成立。支线要有自己的欲望与推动者，并说明它如何影响全书关心的问题；不凑支线数量。人物可以反复挣扎，不必每个单元完成蜕变。

## 近章：只展开当前需要的范围

只细化作者指定的章节或即将起草的范围，不强制固定批次。每章明确核心事件、人物当下目的、行动与结果、对后文的推动力；按章节功能补心理、关系、情绪、生活或信息安排，不要求每章都反转、改变关系或留下强钩子。

分清角色知道什么、读者知道什么、现在可以揭示什么、以后才揭示什么。受限制的章节也应有有效进展，例如检验一种猜想、解决局部困难或改变关系。预定远期真相不能提前泄漏给角色，也不能作为审读时替正文补全的依据。

只核对本次会使用的人物、规则、资源、时间与空间。已有正文具有事实约束，规划中的奖励、承诺与能力不能自动视为已经获得。

## 写后与卷间接续

以正文实际发生的事情更新计划。收卷交代本卷问题的阶段答案、人物得失与留下的影响；高潮后允许收获、生活与关系余波。开新卷承接未决后果，不靠换城市、身份或对手清零历史、有效关系与资源。

重复核心看点时改变处境、选择或意义。发现连续单元都在做同样的事，应合并或改动后果，而不是再增加检查表。

交付可以是全书方向、当前卷纲、指定近章中的任一项或组合。达到作者本次范围、接下来足够落笔就停止扩纲。

当前卷或近期章节中影响人物选择、主线因果、揭示、高潮和收束的关键处，先按 `methods.md` 结合场景卡提出不同方案，比较取舍与跨场景牵连，等作者选好再进入相应正文。远期保留粗线，不要求开写前选完整本书。已经选定的安排直接沿用；普通承接和常规细节自行完成。需要正文时使用本包 `drafting.md`。
