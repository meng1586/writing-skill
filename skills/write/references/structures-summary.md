# 结构安排摘要（通用，不含具体书目/案例）

> 这里只收可试的事件组织与推进方式，供规划时比较。**可叠用，没有固定步骤，也不保证效果**；证据仍待读者反馈。
> 含具体书名章号的完整版是本地私人证据页，不随公开包分发。

## 一、常见安排与适配问题

| 安排 | 主要解决 | 常见用途 | 什么时候不划算 |
|---|---|---|---|
| 一次主要变化 | 短篇/中篇收束，不靠事件数量撑篇幅 | 人物少、场景集中、核心变化清楚 | 当前范围需要多次彼此独立的主要变化 |
| 规则—关卡—反转 | 让读者用规则算生死，再让规则被改写 | 悬疑、规则怪谈、无限流、密室 | 当前问题没有可被理解、利用的规则 |
| 双线交叉互证 | 两条线互为证据，读者自己拼真相 | 悬疑、年代、身份谜题 | 两条线强度差太多；交叉只靠巧合 |
| 单元剧 + 主线 | 单元自洽，主线缓慢推进 | 长篇连载、群像、无限流 | 当前范围无需组织多个单元，或单元与长线彼此无关 |
| 倒计时/限时 | 可见的时间压力，让读者自己算 | 绝境、追逃、救援、灾难 | 时限不影响理解、关系或行动，没有真实后果 |
| 群像多线并行 | 多条线在共同目标或节点上关联 | 群像、战争、末世、大事件 | 没有需要独立推进并发生关联的线索/行动，或线多到读者难以追踪 |
| 阶梯升级/成长弧 | 用可数刻度让读者看见进度 | 玄幻、升级流、竞技、经营 | 当前变化没有适合量化的进展 |
| 秘密分层揭露 | 真相分几层给，每层改变理解 | 悬疑、身份、世界观揭示 | 秘密与人物选择/读者理解无关 |

## 二、可试的安排（示例，不是步骤）

- 一次主要变化：日常 → 裂缝 → 代价 → 选择 → 回到（或回不到）日常。
- 规则—关卡—反转：给规则 → 用规则解题 → 规则失效/被利用 → 更大规则 → 重算前文。
- 双线：A 线现在的问题 + B 线过去的物证 → 互相解释 → 只有合看才成立的结论。
- 单元剧：主线远处的问题 → 单元本地问题 → 单元内解决 → 顺手推进主线一格（可不动）。
- 限时：给时限与代价 → 算账 → 可以断链 → 缩时间/空间 → 结算（可以团圆，也可以不）。
- 群像：各线自己的目标 + 共同 deadline → 靠物件/消息交叉 → 可以有一线失败 → 关联后不总结。
- 升级：可数刻度 → 赢但露短板（可省）→ 补短板但代价变大（可省）→ 旧方法失效 → 刻度上升，可以失去也可以不。
- 秘密：可验证异常 → 按第一层行动（可吃亏可没事）→ 第二层推翻解释 → 重做选择（也可只改变读者判断）→ 留一层或揭完。

## 三、四条失效条件

1. 读者看不到可判断的依据（规则说不清、时限没后果、刻度不可数）。
2. 每一步都对却没有任何变化（信息、关系、代价都不动）。
3. 为了套安排硬加失败、死亡、损失或“同地汇合”。
4. 安排之间互相打架，却没有取舍说明。

## 四、使用方式

- 只在规划或结构卡住时按需选读；已有方向够落笔就不查。
- 结构安排可帮助比较整篇、卷、单元或局部的组织与推进；场景卡帮助比较具体场面的写法。
- 不默认每书挑一套，不按固定章数/比例分配高潮。
- 效果仍待真实读者证据；模型同意与卡片齐全都不算验证。
