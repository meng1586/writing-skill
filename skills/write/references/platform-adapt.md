# 平台适配（可选）：知乎化 / 番茄化

> **默认不启用。** 只有作者明确说「知乎化」「番茄化」「按平台改一版」时才走这条流程。
> 目的：在作者指定的平台与读者情境下，尝试调整阅读呈现。下列手法是待试候选，不是平台规则，也不保证推流、点击或阅读效果；不据此改写原文剧情。
> 本地短篇思路笔记可以按需只读参考，不作为运行依赖或效果证明。公开包不携带私人笔记和作品案例；需要平台当前规则时另行核实。

## 适配边界

1. **剧情事实不变**：先核对唯一原稿版本与本次范围。事件、人物关系、行动动机、知情条件、因果、结局、伏笔均须保留；不新增或删去情节，不换结局。
2. **质量优先**：不为流量塞烂梗、标题失真或强行煽情。按 `editorial.md` 审读实际改动，不把套齐手法当作通过。
3. **保留人设声音和已选安排**：人物说话方式、叙述视角、文风骨架保留。标题剧透、结果前置、反转挪位及断点变化可能显著改变读者知情、期待与悬念，不自动属于已授权的呈现调整；涉及已选关键安排时，按 `methods.md` 比较受影响方案，取得作者选择或明确的本轮代选委托后再改。未获授权就保留原安排。
4. **交付两份**：原文版本不动；另出「平台版」，并在文末列实际改动及其影响。没有合适改动也可原样保留相关部分，不为平台强改。

## 番茄化：按当前文本问题选择候选

- **标题**：可尝试更直接、口语化地突出已有处境或冲突；是否提前透露反转，须服从原稿的信息边界与作者选择，不默认把最大反转放进标题。
- **开头**：若当前开头妨碍理解或进入故事，可比较提前已有行动、冲突或异常的效果；不固定前多少字必须出现什么，天气、背景与世界观有价值时可以保留。
- **段落**：按实际手机阅读、动作连续性与文风调整长段；对话可独立成段，不限定每段句数，也不把连贯段落一律拆碎。
- **节奏与断点**：可比较已有悬念或进展的呈现与断点；不要求每章末都放未解物、问句、数字或爽点，不凭空增设疑问。
- **信息密度**：只调整妨碍理解的集中说明，按当前视角与行动需要分配信息；不限定一次最多给几条设定，必要解释可以保留。
- **情绪**：观察当前铺垫与回应是否成立，再决定详略与节奏；不固定先憋后释放，也不为凑情绪曲线强改人物反应。

## 知乎化：按当前文本问题选择候选

- **标题**：可比较问题式、处境式或悬念式标题是否准确；不强求固定句型，不越过原稿的信息边界。
- **开头**：可让当前人物的处境与关切更清楚，保留既定叙述视角；不默认第一人称更有效，也不把虚构包装成真实经历。
- **信息顺序**：已有结果前置确实合适时可以提出比较，但须先核对它怎样影响因果理解、知情与悬念，并遵守上述选案边界；不默认改为倒叙。
- **段落与语言**：可调整妨碍阅读的冗长或重复，保留人物声音、有效描写、心理与必要解释；短段、口语和少形容词均不是硬要求。
- **反转**：原稿本来有反转才考虑呈现；不新增反转、不固定它在中后段，也不为适配另造铺垫。挪位涉及关键安排时先比较选定。
- **结尾**：按原有收束目标比较详略，允许一句或多段；不统一禁止总结、解释或抒情，也不把留白当必选。

## 对照复验与交付

- 核对实际正文中的事件、人物与关系、行动动机、时空、人物知情、因果、伏笔和结局是否保持；事件或人数相等不能单独证明未改变剧情。
- 对标题、开头、分段、断点和信息顺序的每处改动，说明是否影响读者理解、期待、悬念、视角与人物声音。已选关键安排的改变须能对应作者选择或本轮代选委托。
- 按 `editorial.md` 对改动范围及关联上下文复验，保留成立的原表达；若新生问题无法在授权范围内解决，就撤回该处适配或说明待定，不冒称已通过。
- 交付平台版与简短改动清单，说明实际复查范围、未定项和未验证的平台效果；确认原文未覆盖。完成本次范围后停止，不自动扩成发布或新一轮创作。
