# 开篇：公开摘要

> 保留提炼后的条件与候选办法；原文、来源定位和真实案例留在本地。
> 所有效果均待试验。按当前文本选择，允许不用；固定数量、句式或步骤不作为质量门槛。

## R-开篇-001 用可核查的数字矛盾引出异常

- 适用题材：悬疑 / 无限流 / 密室 / 规则怪谈
- 适用条件：本场需要读者发现异常，计数对象和比较依据足够清楚。
- 可以尝试：并列呈现不一致的计数与眼前事实，留出人物和读者核对的空间。
- 解释（推测）：明确的矛盾可提供推理入口；能否激起好奇取决于读者在乎什么。
- 边界与失败方式：数字含混、核对依据缺失或异常与当前目标无关时，先补依据；直接说明异常也可以。
- 效果状态：待试验

## R-开篇-002 用暴力的后果揭开制度运作

- 适用题材：悬疑 / 无限流 / 惊悚 / 末世
- 适用条件：场景目标是让人物理解危险如何重复发生，而不只交代一次伤害。
- 可以尝试：在事件之后给出可追溯的规则、执行者或利益关系，让说明影响下一步选择。
- 解释（推测）：从事件转向运作机制，可能让危险有可判断的范围和后果。
- 边界与失败方式：不为解释牺牲现场所需反应；随机暴力、未知威胁也可成立，不要求立即揭底。
- 效果状态：待试验

## R-开篇-003 借有后果的行话纠正呈现新人处境

- 适用题材：无限流 / 规则怪谈 / 群像 / 新人入行
- 适用条件：人物确实不熟悉行业用语，称呼差异与当前身份或行动有关。
- 可以尝试：让误用、纠正和随后的选择连在一起，只交代眼下需要的信息。
- 解释（推测）：纠正可同时呈现知识差与关系位置，减少独立说明段的负担。
- 边界与失败方式：不要让人物为教学故意犯傻；没有交互情境时可直接叙述，不必制造口误。
- 效果状态：待试验
