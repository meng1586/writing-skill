# 人物：公开摘要

> 保留提炼后的条件与候选办法；原文、来源定位和真实案例留在本地。
> 所有效果均待试验。按当前文本选择，允许不用；固定数量、句式或步骤不作为质量门槛。

## R-人物-001 先用当前行动与关系锚定人物出场

- 适用题材：都市 / 悬疑 / 玄幻 / 快节奏开篇
- 适用条件：首次出场的信息较多，眼前行动能让读者先辨认人物。
- 可以尝试：选择有辨识度的动作、声音或关系信息，履历在理解当前行动需要时补充。
- 解释（推测）：当前行为可能比集中介绍更容易与后续选择建立联系。
- 边界与失败方式：不固定动作或交代次数；功能性人物可直接说明，前史本身重要时也可提前写。
- 效果状态：待试验

## R-人物-002 借日常习惯的变化呈现关系中的异常

- 适用题材：悬疑 / 民俗恐怖 / 家庭伦理
- 适用条件：读者已有可比较的日常基线，异常与人物秘密或关系变化有关。
- 可以尝试：保留习惯中的稳定部分，再让停顿、遗漏或选择出现差异。
- 解释（推测）：熟悉与变化的对照可能给读者判断关系的依据。
- 边界与失败方式：不要按重复次数验收；基线不足时先建立语境，坦白或直接交代同样可以成立。
- 效果状态：待试验

## R-人物-003 用职业逻辑具体化对立者的行为

- 适用题材：无限流 / 悬疑 / 职场向反派 / 制度冲突
- 适用条件：人物有可信的职业经历，其目标与行业规则影响本场选择。
- 可以尝试：让专业判断、利益和话术进入行动，说明他为何认为自己的做法合理。
- 解释（推测）：职业逻辑可能使对立者区别于抽象的恶意标签。
- 边界与失败方式：术语不能代替人物；非专业身份也可有可信动机，不要求反派一律冷静或礼貌。
- 效果状态：待试验

## R-人物-004 让语言差异回应人物的位置与经验

- 适用题材：群像 / 无限流 / 长篇
- 适用条件：多人交流中，身份、知识或关系差异需要被读出。
- 可以尝试：从人物经历中选择常用概念、称呼和表达习惯，并随谈话对象调整。
- 解释（推测）：词汇与表达方式可能帮助读者识别人及其关系位置。
- 边界与失败方式：不要给每人硬配口头禅；同一人会换语体，说明说话者姓名也不是失败。
- 效果状态：待试验

## R-人物-005 用具体愿望呈现人物不易示人的软肋

- 适用题材：群像 / 悬疑 / 成长
- 适用条件：宏大目标已知，但人物个人想保住或得到什么仍不清楚。
- 可以尝试：让愿望落在可选择的日常可能上，并写出他为何难以承认或实现。
- 解释（推测）：具体愿望可能给抽象目标提供个人分量。
- 边界与失败方式：不要求愿望必须微小或羞耻；宏大理想可以成立，避免只为煽情临时补愿望。
- 效果状态：待试验

## R-人物-006 让能力的使用与既往应对经验相连

- 适用题材：都市异能 / 系统流 / 热血
- 适用条件：需要理解人物为何这样使用能力，过去经验确实影响当前选择。
- 可以尝试：把过去形成的习惯、限制或愿望带入一次能力选择，而非只补能力起源说明。
- 解释（推测）：经历与使用方式相连，可能使能力成为人物的一部分。
- 边界与失败方式：创伤不是能力成立的必要条件；天赋、学习或偶然所得也可成立，不为解释强加伤害。
- 效果状态：待试验
