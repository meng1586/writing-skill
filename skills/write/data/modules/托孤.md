# 场景模块：托孤

> 一句话：呈现一次无法独自继续承担的托付，以及接手者获得的责任与选择权。
> 别名：托付、交棒、临终嘱托、把孩子交出去
> 效果状态：待试验
> 本页为公开描述摘要；原文、来源定位与真实案例留本地。

## 适用条件

- 原承担者将离开、失去能力或改变身份，有人、任务或秘密需要被接续。
- 托付会影响接手者的现实处境，接受、拒绝或附条件都有意义。

## 结构（候选组织，按需要取舍）

以下是可选组织方式，可合并、改序或不用，不按步骤数量验收。

1. 说明原承担者为何需要托付，以及仍有哪些选择。
2. 按关系选择请求、交易、命令或授权的表达，不预定哪种更重。
3. 明确交出的对象、责任和判断权限，保留双方的不同理解。
4. 让接手者以行动或话语作回应，表现其愿意和能够承担的范围。
5. 在后续兑现、失约或调整责任时承接这次托付。

## 解释（推测）

责任与判断权的转移可能使关系变化落到后续生活，而非只停在承诺。

## 崩法与失败方式

- 被托付者只被当作展示主角美德的道具。
- 请求很重，却没有说明接手者为什么接受、为何有能力承担。
- 承诺与后续处境脱节，或为了制造重量强加无法兑现的责任。

## 边界

不要求托付者毫无退路、接手者先拒绝或必须临终；忠诚与主动接受同样可成立。恳求、誓言和沉默都可使用，不强制留凭证。

## 可选变体

- 通常受照顾的一方反过来托付记忆、责任或照顾他人的任务。
- 托给利益冲突的一方，清楚交代别无更好选择的依据与风险。
